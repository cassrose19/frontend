1. Clone the repository -- https://github.com/cassrose19/frontend.git
2. Make sure your backend is up-to-date via the README instructions in https://github.com/jiwoo-jus/MelodyMind.git
3. In your backend's .env file, add the line 'CORS_ORIGINS=http://127.0.0.1:5500,http://localhost:3000,http://localhost:5051'; this allows
   the backend server 5051 to accept cross-origin requests from live server 127.0.0.1:5500
